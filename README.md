# FitBud

和好朋友一起用的微信小程序：种草推荐 · 每日健身打卡 · 坚持奖励。

## 本地打开

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本仓库目录，AppID：`wxae4a7679e4dabdb8`
3. 服务端密钥见 `.env.example`，复制为 `.env` 后填写（**不要提交 `.env`**）

## 安全说明

- **AppID** 可放在 `project.config.json`（客户端可见）
- **AppSecret** 只能放服务端 / 本机 `.env`，禁止写入小程序前端代码或公开仓库
